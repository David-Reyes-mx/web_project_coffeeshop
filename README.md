# Triple Espresso

Triple Espresso
Descripción del proyecto

Triple Espresso es una página web desarrollada como parte del programa de Desarrollo Web de TripleTen. El sitio representa una cafetería moderna y funcional donde los usuarios pueden conocer recetas de café, consultar información sobre el establecimiento y realizar reservas de mesas.

El proyecto fue construido siguiendo la metodología BEM (Block Element Modifier) para organizar la estructura del código y facilitar su mantenimiento. La página está compuesta por varias secciones, incluyendo encabezado, recetas, formulario de reservaciones y pie de página con enlaces a redes sociales.

Tecnologías utilizadas
HTML5
CSS3
Metodología BEM
Flexbox
Posicionamiento CSS
Formularios HTML
Iframes para contenido multimedia
Google Fonts (Inter y Noto Serif)
Planes de mejora

Algunas mejoras que me gustaría implementar en futuras versiones del proyecto son:

Hacer que el sitio sea completamente responsive para dispositivos móviles, tabletas y pantallas de diferentes tamaños.
Agregar validaciones avanzadas al formulario utilizando JavaScript.
Implementar un sistema real de reservas conectado a una base de datos.
Añadir animaciones y transiciones para mejorar la experiencia del usuario.
Incorporar un modo oscuro y opciones de accesibilidad para distintos tipos de usuarios.

Estas mejoras permitirían ofrecer una experiencia más completa e interactiva para los visitantes del sitio.
